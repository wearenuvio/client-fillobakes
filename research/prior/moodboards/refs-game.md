# Fillo Bakes — Moodboard: THE ROUTE AS A GAME

Direction: the van is a **catchable thing**. Customers track it, chase it, find it, and get rewarded with a mark — a stamp, a sticker, a capsule, a card. The route is the game board; each neighbourhood is a node; the live GPS tracker is the map screen.

All image URLs below verified by fetching — every one returns HTTP 200, `image/*`, at 1920px on the long edge (unless noted). Sources are Wikimedia Commons (CC/PD), so they are safe to drop into a client-facing moodboard.

## E. Route-as-board-game

**Tōkaidō sugoroku (Hizakurige)** — an Edo-period Japanese board game laid out as a *journey along a real route*, cell by cell, with a hero panel at centre; this is the Fillo route map redrawn as a game board and is the single best structural reference here.
IMG: https://upload.wikimedia.org/wikipedia/commons/thumb/9/99/Sugoroku_Hiza_kurige_kokkei.jpg/1920px-Sugoroku_Hiza_kurige_kokkei.jpg
Source: https://commons.wikimedia.org/wiki/File:Sugoroku_Hiza_kurige_kokkei.jpg

**1926 pictorial sugoroku world map** — pictorial map + game board fused; illustrated destinations strung along a path, dense and warm; the look for a printed Fillo Bengaluru route board.
IMG: https://upload.wikimedia.org/wikipedia/commons/thumb/8/85/1926_Japanese_pictorial_board_game_sugoroku_map_of_the_world.jpg/1920px-1926_Japanese_pictorial_board_game_sugoroku_map_of_the_world.jpg
