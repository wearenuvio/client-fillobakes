Direction: heritage Japanese print. Single kiln-red ink (#C73E2E) on warm cream (#F5EBD8),
with kraft (#6B4A2F), ink (#2A2118) and an optional indigo accent (#2B4570).
Brush lettering, crest roundel with a bread loaf, letterpress texture, bilingual
lockup with katakana フィロ・ベイクス.

Generated via ChatGPT image generation, one continuous chat so the system stayed
consistent across all four cards. All files 1536 x 1024 PNG (3:2).

  legible) — unusual for image generation and worth preserving.
- The date stamp on ks-2 is baked in as 27 AUG 2025; treat it as placeholder art.
- Aspect ratio came back 1536 x 1024 (exactly 3:2) on all four.
